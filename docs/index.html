How it works

Block. Interrogate. Verdict.

It's a real courtroom procedure, minus the courtroom: the button dies first, then you make your case, then the ruling lands.

step 1 — the block

Buy Now stops working

On checkout pages, an invisible overlay swallows every buy-button click. No willpower required — the click physically cannot land.

step 2 — the interrogation

Make your case

An AI with your profile and purchase history asks what changed. It knows this is your fifth pair of headphones. You get three turns.

step 3 — the verdict

Approved or denied

A real reason (mine broke, I work calls all day) gets a green light and the click goes through. A vibe gets denied — with a cheaper recommendation attached.

Install

Two minutes to a protected wallet

We're not on the Chrome Web Store (yet) — you load it straight from source, like the discerning power user your bank statement says you are not.

  1. Download the extension

    Grab the zip and unzip it anywhere you'll remember.

  2. Open chrome://extensions

    Toggle Developer mode on (top-right corner).

  3. Load unpacked

    Click Load unpacked and select the unzipped extension folder.

  4. That's it — go shopping

    The interrogation brain is hosted for the hackathon (rate-limited, stores nothing). Your profile and history never leave your browser.

# optional — self-host the brain instead of using ours
$ git clone https://github.com/Parth12358/SwiperNoSwiping-compiled
$ cd SwiperNoSwiping-compiled/server
$ python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
$ cp .env.example .env # add your DEEPSEEK_API_KEY
$ .venv/bin/uvicorn main:app --port 8000 # + point extension/config.js at it

requires: Chrome 114+ · a shopping problem · (self-hosting only: Python 3.11+ and a DeepSeek key)

Objections

Asked and answered

Can't I just open DevTools and delete the overlay?

Yes. If you're the kind of person who opens DevTools to buy headphones, you've earned them. This is a speed bump for the 0.4-second impulse click, not a prison.

What if it blocks something I actually need?

Medical, food, safety, and work-required items are approved instantly — no questions, score 100. And if anything ever breaks (server down, timeout, bad response), the extension fails open: the overlay comes off and your purchase goes through. It will never trap you on a checkout page.

Where does my data go?

Your profile and purchase history live in your browser (chrome.storage — JSON on your machine). Each interrogation sends the product plus that context to our hosted brain, which forwards it to DeepSeek for a verdict and forgets it — nothing is stored server-side, there are no accounts, and removing the extension deletes everything. No tracking, no ads targeting your weaknesses — the ad slot is a static joke.

Which sites does it work on?

Amazon and Best Buy today, plus a bundled demo page. The detector is two-layer (known selectors, then text matching), so more retailers are a manifest line away.
